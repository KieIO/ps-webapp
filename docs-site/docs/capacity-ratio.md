# Cấu hình tỷ lệ CM / quản lý

**Tỷ lệ CM / quản lý (%)** (`taskConversionRatio`) nhân với Capacity / ngày để ra [điểm task CM](/capacity-formula/task-points).

Trước: [Capacity / ngày](/capacity-formula) · Sau: [Điểm task CM](/capacity-formula/task-points)

---

## 1. Vào đâu?

Cùng trang **Settings → Capacity formula** — cột tỷ lệ cạnh Capacity / ngày.

---

## 2. Ý nghĩa

| Vai trò / title                 | Tỷ lệ điển hình                                 |
| ------------------------------- | ----------------------------------------------- |
| Staff thường                    | **100%** → điểm task CM ≈ Capacity / ngày       |
| PM / Creative Manager (quản lý) | &lt; 100% (ví dụ 30%) — chỉ phần “điểm task CM” |

Ví dụ FAQ: PM-5 capacity 994 × 30% = **298** điểm task CM.

Sửa tỷ lệ → blur / lưu → cột Điểm task CM cập nhật.

---

## 3. Tóm tắt

1. Sửa **Tỷ lệ CM / quản lý** trên Capacity formula theo title.
2. Dùng để giảm / giữ phần điểm đưa vào Tracker so với Capacity đầy đủ.
3. Staff 100%; quản lý thường thấp hơn.
