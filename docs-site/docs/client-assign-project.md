# Gắn client vào project

Gắn khách hàng vào dự án khi **tạo / sửa project**. Client phải có trong catalog trước.

Catalog: [Thêm / sửa / xóa khách hàng](/clients) · Knowledge: [Ghi chú theo client](/clients/knowledge)

---

## 1. Sơ đồ

```text
Có client trong Settings → Client management
      │
      ▼
Create Project / Edit Project → chọn Client (bắt buộc)
      │
      ▼
Chi tiết client → tab Projects: danh sách project đã gắn
```

---

## 2. Ai gắn được?

| Việc                              | Ai làm được                                       |
| --------------------------------- | ------------------------------------------------- |
| Chọn Client khi tạo / sửa project | Role được tạo / sửa project (theo quyền Projects) |
| Xem project theo client           | Ai mở được chi tiết client / project              |

Tạo client mới: chỉ Head / Admin / Creative Head trên Client management. Trên form project thường chọn client có sẵn (một số flow Head/Admin có thể thêm nhanh tùy UI).

---

## 3. Các bước

1. Mở **Create Project** hoặc **Edit Project**.
2. Trường **Client** (bắt buộc) → chọn khách hàng.
3. Lưu project.

### Xem lại

- **Settings → Client management** → click tên client → tab **Projects**: các project đã gắn client đó.
- Chi tiết project cũng hiện client đã chọn.

---

## 4. Tóm tắt

1. Tạo client trước (nếu chưa có).
2. Create / Edit Project → chọn Client → Save.
3. Tab Projects trên chi tiết client liệt kê các project đã gắn.
