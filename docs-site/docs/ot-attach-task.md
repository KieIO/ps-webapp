# Gắn project task vào request OT đã duyệt

Gắn task sau khi request đã **Đã duyệt**.

Trước: [Duyệt OT](/overtime/approve) · Sau: [Staff làm OT](/overtime/work)

---

## 1. Ai gắn?

| Việc                      | Ai làm được           |
| ------------------------- | --------------------- |
| Gắn task OT sau khi duyệt | Người có quyền xin OT |

---

## 2. Điều kiện

Request phải ở trạng thái **Đã duyệt**.

**Làm gì:**

- Chọn một **project task** cùng dự án để gắn, hoặc **Tạo task mới** rồi gắn
- Staff và khung giờ OT đã có từ bước [xin OT](/overtime)

**Task được gắn phải:**

- Là project task của đúng dự án OT
- Chưa Finished / Cancelled
- Chưa gắn OT request khác
- Chưa giao cho Staff khác (nếu chưa có người nhận, hệ thống gán Staff OT khi gắn)

---

## 3. Sau khi gắn

- Trạng thái → **Đang làm**
- Staff nhận thông báo task OT
- Staff làm việc và nộp giờ: [Staff làm OT](/overtime/work)

---

## 4. Tóm tắt

1. Chỉ gắn khi request **Đã duyệt**.
2. Chọn task sẵn hoặc tạo task mới cùng project.
3. Gắn xong → **Đang làm** → Staff nhận việc.
