# Head / Admin duyệt hoặc từ chối OT

Xử lý request đang **Chờ duyệt**.

Trước: [Xin OT](/overtime) · Sau khi duyệt: [Gắn project task](/overtime/attach-task)

---

## 1. Ai duyệt?

| Việc                    | Ai làm được |
| ----------------------- | ----------- |
| Duyệt / từ chối request | Head, Admin |

Creative Head có thể **xin** OT nhưng **không** duyệt request.

Có thể duyệt nhanh các request **Chờ duyệt** từ **Home** (Head / Admin) hoặc menu **Overtime**.

---

## 2. Nếu duyệt

- Trạng thái → **Đã duyệt**
- Người xin nhận thông báo
- Tiếp theo: [gắn project task](/overtime/attach-task)

---

## 3. Nếu từ chối

- **Phải** nhập lý do từ chối
- Người xin nhận thông báo kèm lý do
- Trạng thái → **Từ chối**
- Luồng kết thúc (không gắn task)

---

## 4. Lưu ý

- Chỉ sửa request khi còn **Chờ duyệt**. Đã duyệt / từ chối thì không sửa được.
- Duyệt request **khác** [review kết quả](/overtime/review) sau khi Staff nộp giờ thực tế.

---

## 5. Tóm tắt

1. Head / Admin mở request **Chờ duyệt**.
2. Duyệt → **Đã duyệt** → gắn task.
3. Từ chối → nhập lý do → kết thúc.
