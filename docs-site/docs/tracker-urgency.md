# Quản lý mức urgency (mức ưu tiên)

Đổi mức ưu tiên project trên Project Tracker qua **chấm màu** cạnh tên project.

Liên quan: [Danh sách trên timeline](/tracker) · [Mốc giao](/milestone)

---

## 1. Ai đổi được?

| Việc                     | Ai làm được                 |
| ------------------------ | --------------------------- |
| Đổi urgency trên Tracker | **PM**, **Head**, **Admin** |
| Xem chấm / mức ưu tiên   | Ai xem được Tracker         |

Creative Head / Employee thường **không** đổi urgency trên Tracker.

---

## 2. Cách làm

1. Mở **Project Tracker**.
2. Trên hàng project, click **chấm urgency** cạnh tên.
3. Chọn mức (hoặc Auto theo rule sản phẩm nếu có).

Thanh / viền hàng project phản ánh màu urgency đã chọn.

Cũng có thể quản lý urgency khi tạo / sửa project (form Project) — go-live hạng mục Projects.

---

## 3. Tóm tắt

1. Click chấm màu trên hàng project → đổi mức ưu tiên.
2. PM / Head / Admin được đổi; role khác chủ yếu xem.
