# Head / Admin review kết quả OT

Duyệt hoặc từ chối kết quả sau khi Staff đã Finished và nhập giờ thực tế (request **Chờ review**).

Trước: [Staff làm OT](/overtime/work) · Theo dõi giờ: [Theo dõi giờ ước tính / thực tế](/overtime/tracking)

---

## 1. Ai review?

| Việc              | Ai làm được |
| ----------------- | ----------- |
| Review kết quả OT | Head, Admin |

Chỉ Head hoặc Admin — **không** phải PM / CM / CH.

Khác với [duyệt request xin OT](/overtime/approve) lúc đầu.

---

## 2. Nếu duyệt kết quả

- Trạng thái → **Hoàn thành**
- Người xin nhận thông báo
- Giờ ước tính / thực tế vào [Dashboard](/overtime/tracking)

---

## 3. Nếu từ chối kết quả

- **Phải** nhập ghi chú / lý do
- Request quay lại **Đang làm**
- Giờ thực tế và ghi chú staff trên OT bị xóa
- Task OT về **Chưa cập nhật** để Staff làm và nộp lại

---

## 4. Tóm tắt

1. Head / Admin mở request **Chờ review**.
2. Duyệt → **Hoàn thành**.
3. Từ chối → Staff nộp lại (Đang làm, xóa giờ thực tế).
