# Xem danh sách project trên timeline

Hướng dẫn xem hàng project trên **Project Tracker**: thanh timeline theo tháng / ngày.

Liên quan: [Khối lượng theo ngày](/tracker/workload) · [Mốc giao](/milestone) · [Task trên project và Tracker](/project-task-views)

---

## 1. Vào đâu?

Menu **Project Tracker** (quyền xem capacity / tracker đầy đủ).

Mỗi project là **một hàng**: tên project, team, tổng slides, và **thanh timeline** theo cột ngày.

---

## 2. Timeline hiển thị gì?

- Lịch theo **tháng** (đổi tháng trên header calendar).
- Thanh project kéo theo **ngày bắt đầu – kết thúc** (múi giờ **Việt Nam**).
- Ô task màu theo **ngày task** (không theo deadline) — xem [Khối lượng theo ngày](/tracker/workload).
- [Chấm mốc giao](/milestone) trên thanh.
- [Chấm urgency](/tracker/urgency) cạnh tên project.

:::note[Ngày VN]

Deadline / mốc hiển thị **16/10** phải khớp cột **16/10** trên thanh — không lệch vì UTC.

:::

---

## 3. Ai xem / chỉnh timeline?

| Việc                                       | Ai làm được                 |
| ------------------------------------------ | --------------------------- |
| Xem danh sách project trên Tracker         | Ai vào được Project Tracker |
| Sửa ngày bắt đầu / kết thúc (Edit Project) | PM, Head, Admin             |

Chi tiết quyền PM: [FAQ — PM trên Project Tracker](/faq).

---

## 4. Tóm tắt

1. Project Tracker → mỗi project một hàng + thanh theo ngày.
2. Đổi tháng để xem đoạn timeline khác.
3. Ngày trên Tracker dùng lịch Việt Nam.
